**NeMo OSS** is the hub for NVIDIA's public, open source NeMo work — the [NVIDIA-NeMo](https://github.com/NVIDIA-NeMo) GitHub organization and **docs.nvidia.com/nemo**. It is a discovery layer, not a single product: focused libraries you can adopt individually, plus two named stacks:

- **NeMo Framework** — model lifecycle (data → train → align → evaluate → deploy)
- **NeMo Platform** — agent integration (evaluate, secure, tune, deploy agents)

These projects are part of the broader [NVIDIA NeMo](https://www.nvidia.com/en-us/ai-data-science/products/nemo/) software suite, which also includes commercial products beyond this catalog.
